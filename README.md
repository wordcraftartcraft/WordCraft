## Getting Started
1. Download `wordcraft-0.7.0-windows-x64-portable.zip`.
2. Extract. Run `wordcraft.exe`.
3. Open a .docx or start from the sample handbook.
4. Styles / track changes from the ribbon.
5. Notes in `files/notes/`.
